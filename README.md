# Native-e-comerce-Website
Native E-Commerce Website adalah sebuah platform toko online dinas yang dibangun menggunakan teknologi web dasar (Native) tanpa menggunakan framework eksternal. Proyek ini dirancang untuk menangani proses belanja online mulai dari manajemen produk hingga simulasi transaksi, fokus pada performa yang ringan dan struktur kode yang mudah dipahami.
