🐛 TROUBLESHOOTING

❌ "Connect Failed" error?
✅ Solution:
   1. Check MySQL running (XAMPP Control Panel)
   2. Verify credentials in db/koneksi.php
   3. Default: root (no password)

❌ "Table doesn't exist" error?
✅ Solution:
   1. Open http://localhost/phpmyadmin
   2. Import db/schema.sql
   3. Make sure database 'webp' exists

❌ Can't login?
✅ Solution:
   1. Check username spelling (case-sensitive)
   2. Password: password (lowercase)
   3. Or use test user: testuser / password

❌ Cart empty after logout?
✅ Normal! Cart uses session (destroyed on logout)

More help? → Read SETUP.md troubleshooting section
